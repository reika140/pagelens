# PageLens v1.5.0

A cleaner, faster way to inspect the webpage you are viewing in Chrome.

### What is included

- **Metadata first:** Index/Follow indications, title, description, canonical, Open Graph, X cards, and hreflang.
- **Headings and images:** Read the heading outline, copy headings, inspect image thumbnails and alt text, and export image data.
- **Links:** Browse internal and external links, export CSV, and check HTTP responses across the current page with **Check all**, progress, Stop, and Resume.
- **Structured data:** Inspect JSON-LD types, syntax, and formatted content.
- **Optional visual tools:** Automatic organic-result numbers on supported Google searches; on-demand colored outlines for Follow, Nofollow, and UGC links.
- **Refined interface:** Compact popup, clearer labels, light/dark themes, and local-first processing.

### Install

Download **pagelens-v1.5.0-chrome-extension.zip** from Assets below, extract it, then open <code>chrome://extensions</code>, enable Developer mode, and select **Load unpacked**. Choose the folder containing <code>manifest.json</code>.

No account or payment is required.

### Before using

This is a **beta release**, not a Chrome Web Store installation. The HTTP checker sends requests to linked websites only when you click **Check all**; some external links cannot be verified because of CORS. Keep the popup open during HTTP checks. Google organic numbering is best-effort and is not a rank-tracking service.

Source code is available in the repository and in the source ZIP attached to this release. Report issues at https://github.com/reika140/pagelens/issues.
